# **FLASHCARDS-WEB**

Завершенное дипломное веб-приложение для изучения иностранных языков.

Использованный стек технологий:
  Identity для авторизации.
  Html, CSS, JavaScript для фронта. Были также задействованны асинхронные возможности JS - Ajax.
  Шаблон проектирования MVC с чистой архитектурой.

Решение работает с SqLite и по возможности разбито на регионы для лучшей навигации. В приложении предусмотрена единственная сессия на пользователя. Следующий вход обнуляет предыдущий.
