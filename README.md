# 💻 FLASHCARDS-WEB

A completed diploma web application for learning foreign languages.  
Built with **ASP.NET Core MVC** following Clean Architecture(First attempt. So, not perfect) principles.

---

## 🧩 Tech Stack
- 🧱 **ASP.NET Core MVC** — main backend framework  
- 🔐 **Identity** — authentication and authorization  
- 🎨 **HTML, CSS, JavaScript (AJAX)** — frontend  
- 💾 **SQLite** — lightweight database  
- 🌐 **Localization support** — multi-language interface  
- 🧹 **Clean Architecture + regions** — organized and maintainable structure  

---

## ✨ Features
- User authentication (only one active session per account)  
- Multi-language **localization** support (English / Russian)  
- Create, rename, delete, and manage word sets  
- Study mode with audio playback and voice selection  
- Favorites and image zoom options  
- Modern, responsive UI (no external frameworks)
